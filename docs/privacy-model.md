# EFF ApplyAll privacy model

Students own their Future Passport. Data is collected only for selected journey tasks and is not copied into scholarship applications automatically. Supporter access is category-specific, revocable, and denied by default. Navigators see assigned, necessary information only. Sensitive essays, conduct responses, disability information, credentials, and authentication codes are not exposed to supporters.

Production must provide export, deletion, retention, consent-version, and session-revocation workflows before real student onboarding. Identifiable student information is never sold and is excluded from general logs and test fixtures.
