# Live-submission readiness

- [ ] University route and receiving method are allowed by applicable terms and law.
- [ ] Requirements, fees, deadlines, certifications, and supplements have verified sources.
- [ ] Driver contract, accessibility, mobile, failure, idempotency, and receipt tests pass.
- [ ] CAPTCHA, MFA, payment, signatures, and attestations pause for the student.
- [ ] Credential/session storage and deletion have security approval.
- [ ] Build approval and submission approval are separate and recorded.
- [ ] Production secrets, alerts, retention, support, rollback, and incident procedures are ready.
- [ ] `ENABLE_LIVE_APPLICATION_SUBMISSION` remains false until the controlled pilot is authorized.
