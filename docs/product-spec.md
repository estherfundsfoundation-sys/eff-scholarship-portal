# EFF ApplyAll product rules

EFF Apply Everywhere is a distinct student-continuity product inside the EFF portal. Its public promise is **Start Here. Go Anywhere.** Students create a Future Passport, select supported institutions, answer reusable questions once, resolve student-only checkpoints, review immutable application snapshots, and authorize an exact batch.

The first release is a safe demonstration using three fictional institutions. It must never imply that a real application was submitted. A real route may not build or submit until route-specific operational review, tests, and approval are recorded.

The student remains the decision-maker. EFF does not invent facts or essays, bypass CAPTCHA or MFA, sign attestations, authorize binding admission, or pay fees without explicit student action.
