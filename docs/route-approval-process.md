# Route approval process

1. Create an institution record with authoritative source metadata.
2. Map and version the route manifest.
3. Run the shared driver contract and change-detection tests.
4. Review terms, privacy, operational risk, and student checkpoints.
5. Approve build separately from submission.
6. Run a controlled, consented pilot.
7. Verify the official receipt and duplicate prevention.
8. Monitor changes and pause on material, security, or unknown changes.

No global flag overrides a route that lacks route-level approval.
